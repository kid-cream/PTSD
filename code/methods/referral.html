心理科转诊与咨询指引

如何预约专业心理咨询与评估（高风险人群参考）

一、什么情况建议转诊心理科

  • 风险评估提示为高风险人群，或围产期 PTSD 问卷得分较高；
  • 情绪低落、焦虑、易怒等持续超过 2 周，且影响日常生活；
  • 反复出现与分娩相关的噩梦、闯入性回忆，或明显回避相关情境；
  • 睡眠严重障碍、注意力明显下降、感到麻木或与他人疏离；
  • 出现伤害自己或宝宝的想法。

二、转诊流程建议

  1. 产科门诊首诊：向产科医生说明情况，由医生评估并开具转诊意见。
  2. 心理科 / 精神科门诊：携带转诊意见与既往评估结果，预约心理科门诊，由专业人员进一步评估。
  3. 专业评估：医生或心理治疗师会进行访谈与量表评估，明确是否存在 PTSD 或抑郁、焦虑等问题。
  4. 制定干预方案：根据评估结果制定干预计划，可能包括心理咨询、心理治疗或必要的药物治疗（用药需医生评估哺乳期风险）。

三、就诊前可以做什么

  • 记录主要困扰的症状、开始时间、频率与触发因素，便于就诊时清晰表述；
  • 整理既往孕产情况、分娩经过及重要生活事件；
  • 尽量由家人陪同，减轻就诊压力。

四、关于治疗的说明

围产期心理问题经过规范治疗，多数预后良好。常用的干预包括认知行为疗法、支持性心理治疗、眼动脱敏与再加工等。请放心与专业人员充分沟通，遵医嘱选择适合的方案。

请在工作人员或家属陪同下进行转诊，切勿拖延。早期专业干预是恢复的关键。

温馨提示：具体转诊流程与科室安排以本院实际情况为准。本内容为一般性指引，不构成诊断或治疗方案。

本工具仅用于风险评估参考，不构成临床诊断。如有心理困扰，请及时寻求专业帮助。
